# Categorías

Las categorías agrupan los videos del catálogo (por ejemplo: *Resúmenes*,
*Goles*, *Entrevistas*). **Todo video debe pertenecer a una categoría**, así que
conviene crear las que necesites antes de empezar a subir.

El sistema ya viene con un set inicial sembrado: *Resúmenes, Goles, Entrevistas,
Análisis, Destacados*. Puedes usarlas, editarlas o crear las tuyas.

## Crear una categoría

1. En el menú lateral entra a **Categorías**.
2. Haz clic en **Nueva categoría** (arriba a la derecha).
3. Completa el formulario:
   - **Nombre** *(obligatorio)* — debe ser único. Ej: `Resúmenes`.
   - **Descripción** *(opcional)* — texto breve de referencia interna.
   - **Orden** — número para ordenar las categorías (menor aparece primero).
4. Haz clic en **Guardar**.

> El identificador para URLs (*slug*) se genera solo a partir del nombre; no hay
> que escribirlo.

## Editar una categoría

1. En la lista, haz clic en **Editar** en la fila de la categoría.
2. Cambia los campos y **Guarda**.

## Eliminar una categoría

1. Haz clic en **Eliminar** en la fila correspondiente y confirma.
2. **No se puede eliminar una categoría que tenga videos asociados.** Primero
   mueve o elimina esos videos, o reasígnalos a otra categoría.

## La columna "Videos"

La lista muestra cuántos videos tiene cada categoría. Es útil para saber qué
categorías están en uso antes de intentar eliminarlas.
